# Expense Tracker (Django + DRF)

A simple **Expense Tracker** web app built using **Django** and **Django REST Framework**.

This project was created as part of my **30 Days Python + Django Bootcamp** and includes:
- User Authentication (Login / Signup / Logout)
- Expense CRUD (Create, View, Edit, Delete)
- REST API (Token Authentication)
- Pagination + Filtering + Search + Ordering
- Environment Variables using `.env` (python-decouple)
- Deployment Ready (Render)

---

## 🚀 Features

### ✅ Web App
- Signup
- Login
- Logout
- Add expenses
- View expenses list
- Edit expenses
- Delete expenses

### ✅ API (Django REST Framework)
- Token Authentication
- List/Create expenses
- Pagination
- Filtering
- Search
- Ordering

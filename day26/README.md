# Expense Tracker API (Day 26) 🚀  
### Django REST Framework – Pagination + Filtering

This project is part of my **Python + Django REST Framework learning journey**.  
On **Day 26**, I implemented **Pagination** and **Filtering** for the Expense API using DRF.

---

## 📌 Features Implemented (Day 26)

✅ Expense API (GET / POST)  
✅ Token Authentication (DRF Token Auth)  
✅ Pagination (PageNumberPagination)  
✅ Filtering using `django-filter`  
✅ Search support  
✅ Ordering support  

---

## 🛠 Tech Stack

- Python 3.x  
- Django 5.x  
- Django REST Framework (DRF)  
- Django Filters (`django-filter`)  
- SQLite3 (default)

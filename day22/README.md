# 📅 Day 22 – Django REST Framework (DRF) Intro

## 📌 Goal
Understand the concept of APIs and build a simple REST API using Django REST Framework for the Expense Tracker app.

---

## 🚀 What I Learned

- What an **API** is and why it is needed
- Difference between **UI-based apps** and **API-based systems**
- What **JSON** is and why it is used
- Basics of **Django REST Framework (DRF)**
- How backend data is shared with external systems

---

## 🛠️ Concepts Covered

### 1️⃣ API (Application Programming Interface)
- Allows different applications to communicate
- Example: Mobile app ↔ Backend server

### 2️⃣ JSON (JavaScript Object Notation)
- Lightweight data format
- Easy for humans and machines to read
- Used by APIs to send and receive data

Example:
```json
{
  "name": "Tea",
  "amount": 250
}
